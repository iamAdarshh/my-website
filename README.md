# Adarsh Choudhary - Portfolio Website

A minimal, professional personal portfolio built using React, TypeScript, Tailwind CSS v4, and Vite+. 

## 🚀 Technologies Used
- **Frontend Framework**: React + TypeScript
- **Styling**: Tailwind CSS v4
- **Toolchain**: [Vite+](https://viteplus.dev/) (Unified toolchain combining Vite, Rolldown, Vitest, Oxlint, etc.)
- **Package Manager**: pnpm

## 📦 Getting Started

1. **Install the Vite+ CLI** (if you haven't already):
   - macOS / Linux: `curl -fsSL https://vite.plus | bash`
   - Windows (PowerShell): `irm https://vite.plus/ps1 | iex`

2. **Install Dependencies**:
   ```bash
   vp install
   ```

3. **Start the Development Server**:
   ```bash
   vp dev
   ```
   Open `http://localhost:5173` to view it in the browser.

## 🛠️ Scripts & Commands
Since this project uses Vite+, all commands are run through the `vp` CLI:
- `vp dev` - Starts the development server.
- `vp build` - Builds the app for production (outputs to `/dist`).
- `vp check` - Runs formatters, linters, and type-checking.
- `vp check --fix` - Automatically fixes formatting and linting errors.

## 🎨 Design System
- **Typography**: Inter (Google Fonts)
- **Icons**: Material Symbols Rounded
- **Color Palette**: Minimalistic Zinc/Stone palette.
